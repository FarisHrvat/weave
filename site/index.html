Git, files and terminals in one app.

Weave is a free desktop app for macOS, Windows and Linux. Commit and review code, move files to your servers and cloud storage, and work in SSH terminals without switching between three programs. There is no account and no telemetry.

Weave is an alpha. Read the known limits before relying on it for important work.

What it does

Git

Stage lines or hunks, commit, push and pull, browse the graph and blame, plan an interactive rebase, resolve conflicts, and work with worktrees, Gitflow, submodules and Git LFS. Pull requests, issues and CI checks for GitHub, GitLab, Bitbucket and Azure DevOps.

Files

Two panes for local folders, SFTP, FTP, FTPS, WebDAV, S3, Azure Blob Storage, Dropbox, Google Drive and OneDrive. A transfer queue with pause, resume and checksums, folder compare and sync, and scheduled sync jobs.

Terminals

Local shells and SSH, plus Telnet, serial, Mosh, X11, VNC and RDP. Tabs and splits, broadcast input, search across tabs, recording, triggers, snippets and shell integration.

Hosts

Import from OpenSSH, FileZilla, WinSCP, PuTTY, MobaXterm, Cyberduck, SecureCRT and Termius. Passwords and two-factor codes are asked once and shared between the terminal and Files. Tunnels, jump hosts and port knocking.

Download

Get the installer for your system from the latest release. Each release lists SHA-256 checksums for its files.

SystemInstallerNeeds
macOS 11 or newer .dmg for Apple Silicon (aarch64) or Intel (x64) Nothing extra. Git comes with the Xcode command line tools.
Windows 10 or 11, 64-bit -setup.exe or .msi Git for Windows. OpenSSH and WebView2 come with Windows.
Linux x86_64: Ubuntu 22.04, Debian 12, Fedora 38 or newer .deb, .rpm or .AppImage WebKitGTK 4.1, Git and OpenSSH, which the packages install.

The installers are not signed with a paid certificate, so the first launch shows a warning. On macOS, open System Settings, then Privacy & Security, and click Open Anyway. On Windows, click More info, then Run anyway. You can also build Weave from source.

How it works on each system

Weave is built with Tauri, Rust and SolidJS. It uses the tools your system already has: your own git and OpenSSH, so your keys, agent and known_hosts work as they do in a normal terminal.

Privacy

Weave has no account, no telemetry, no analytics and no automatic updates. Your hosts and history stay on your computer and your passwords stay in your system's credential store. The app connects only to the servers you set up, and to Anthropic only if you press one of the optional AI buttons with your own API key.

This website sets no cookies and loads no scripts, fonts or trackers. It is hosted on GitHub Pages, so GitHub receives standard request data such as your IP address. The full notice is in PRIVACY.md.

Security

Secrets never go into Weave's database, logs or exports. SSH prompts are answered over a private channel with a one-time token, server file names are checked so a hostile server cannot write outside your folder, and settings vaults are encrypted with AES-256-GCM and Argon2id. Weave has not had an independent audit. SECURITY.md has the details and says how to report a problem privately.
